# AI data handling

Where AI-related user data leaves Trakwyn, and which code makes each privacy-policy claim true (JEF-549). The policy text is `legal.privacy.*` in `apps/web/src/i18n/*.json`, rendered by `apps/web/src/routes/-components/PrivacyPage.tsx`. It has not had legal review.

**Last checked: 2026-11-11**

`apps/api/src/__tests__/architecture/aiDataHandling.test.ts` fails when a setting listed under "Enforced by" changes, and names the privacy key and the row to update. Change a flow, the policy and this file in the same PR.

## Review

These go stale without a code change. Re-check them when a ticket touches a flow, and before launch.

- **Cloudflare's Workers AI sub-processors.** The policy names CoreWeave (United States) and Nebius (England). Compare with Cloudflare's published list. Key: `legal.privacy.aiHostedBody`, `aiRegion`.
- **Workers AI data usage.** https://developers.cloudflare.com/workers-ai/platform/data-usage/ must still say content is not kept or trained on. Key: `aiHostedNoTrainingBody`, `aiHostedRetentionBody`.
- **Tavily's terms and privacy policy.** https://www.tavily.com/privacy. Key: `webSearchBody`.
- **The provider links above.**
- **Workers AI prompt caching (JEF-496).** If it ships, prefix caching may hold prompts briefly. Update the Hosted LLM row, the retention sentence and the guard test in that PR.
- **Non-AI sub-processors** are out of scope here; see JEF-132.
