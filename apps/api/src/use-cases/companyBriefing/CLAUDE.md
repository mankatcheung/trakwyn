## Company site research (JEF-475)

A briefing used to rest on the model's memory alone, so for a company it did not know it was generic. `GenerateCompanyBriefingUseCase` now reads what the company says about itself first, hands those pages to the model as numbered, fenced data, and saves the pages it used as the briefing's `sources`.

- **Port and adapters.** `ICompanyResearchSource.research({ company, jobUrl })` returns `{ pages }` or `null` (`use-cases/ports/`). `FetchCompanySiteResearchSource` (`infrastructure/companyResearch/`) is the only implementation; `CachedCompanyResearchSource` wraps it in `http/di/infrastructure.ts` (`companyResearchSource`, `asFunction` because the decorator's `inner` is not a registration). A search provider (Tavily was chosen for it) would be a second implementation behind the same port, so the use case does not change.
- **Which site.** `companySiteOrigin(jobUrl)` takes the posting link's host, drops a hiring subdomain (`careers.`, `jobs.`, `www.` …, `COMPANY_RESEARCH.HIRING_SUBDOMAINS`) and returns `https://<host>`, or `null` for no link, a non-web scheme, a bare hostname, or a job board (`COMPANY_RESEARCH.JOB_BOARD_HOSTS`, matched on the host or a parent). A job board hosts many companies, so its link says nothing about this one. With no usable link there is no research and the briefing is written as before. Only the host is kept: the path and query of a posting link never reach the company's server. The root and the first of `ABOUT_PATHS` that answers with text are the only requests.
- **Outbound fetch rules** are the job-posting ones: every request and redirect hop goes through `IOutboundUrlPolicy` with purpose `company-research`, redirects are followed by hand (`MAX_REDIRECTS`), the body is read with `readBounded` (`MAX_BYTES`), and only `text/html` is kept. Text is made by `htmlToText`, preferring a `<main>` with real content, and cut at `MAX_CHARS_PER_PAGE`. A page under `MIN_PAGE_CHARS` is a script-rendered shell and is skipped.
- **Never fatal.** The adapter swallows a refused URL, a timeout or a bad page per page and answers `null` when none is left; the use case also treats a throwing source as "nothing read". An unreachable site never costs the user a briefing.
- **Shared between users.** The cache is keyed `company-research:<VERSION>:<host>` for `COMPANY_RESEARCH.TTL_MS` (a week), so the host alone is the key and nothing about one user's application is visible to another. `getOrSet` single-flights. An empty answer is deleted straight after, so a site that was down for a minute is retried by the next briefing instead of being remembered as having no pages. **Bump `COMPANY_RESEARCH.VERSION` when what is read or how it is cleaned changes.**
- **Budget and the sources list.** `fitResearch` keeps pages in order until `AI_PROMPT_INPUT.COMPANY_BRIEFING_RESEARCH_MAX_CHARS`. The same fitted list is numbered in the prompt and saved, so a source is never listed that the model did not see. Only `url` and `title` are saved (`CompanyBriefing.sources`, a `jsonb` column with a default of `[]`); the page text is not kept.
- **Prompt.** `companyBriefingPrompt` (version 3) fences the pages with `wrapUntrustedContent`, tells the model to cite `[n]` after each claim drawn from them, to say so when a section is not covered, and to leave out time-sensitive claims (funding, layoffs, leadership) unless a numbered page states them. With no pages it behaves as version 2 did and does not cite. A page is third-party text, so an instruction in one is data: `briefing-ignores-orders-in-a-page` in the evals covers it.
- **Evals.** `evals/cases/briefing.ts` runs the real use case against an invented company's pages (`fixtures/briefingFixtures.ts`): grounded, an injection in a page, one page only, and no page. The checks are mechanical (cites only pages that were given, uses a fact only the pages hold, leaves out funding the pages never state), not a judge.
- **Clients.** `CompanyBriefing.sources { url title }` is a new field, so an app that never asks for it is unaffected. Web and mobile list them numbered to match the citations and open only `http(s)` addresses. Web's disclaimer says "from the company's own website" only when there are sources.
- **Not done here.** A paid search (news, funding, reviews) is a follow-up behind the same port, and the company's site is not found when the application has no posting link or only a job-board link.
