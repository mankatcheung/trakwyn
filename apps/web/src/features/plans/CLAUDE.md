# Plans and locked previews (JEF-344)

Loaded when working under `apps/web/src/features/plans`. The rest of the web notes are in `apps/web/CLAUDE.md`. Paths are relative to `apps/web/src/` unless stated.

- **`PLAN_REQUIRED` is an upgrade prompt, not a failure.** `ErrorState` and `AiErrorMessage` branch on it, and the forms that can hit it (new application at the cap, share link) render `UpgradePrompt`. The text is the API's own message, which names the feature; the link goes to **Settings → Plan**.
- **`useBillingStatus()`** (`features/plans/lib/billingStatus.ts`) is the one reader of `billingStatus`. Settings → Plan shows the plan, usage against each limit and a Free/Pro comparison built from the API's `catalogue`, so no limit is copied into the web app. Buying Pro arrives with billing (JEF-426).
- **Locked previews (JEF-523, JEF-693).** `LockedFeatureOverlay` (`features/plans/components/`) covers a whole Pro-only page for a Free user: a dimmed, `inert` picture of the real page, an "Available on Pro" badge and a link to Settings → Plan, which fires `upgrade_clicked {source: 'locked_preview', feature}`. The picture is the marketing crops of the seeded demo account (`crop-analytics-stats`, `crop-stage-funnel`, `crop-channels`, `crop-offers`, in both themes), never the viewer's data, so none of the user's real figures sit beside the lock and the gated queries never fire. It replaced blurred, fictional bars and rows, which read as a decoy. A new locked page needs a crop in `features/marketing/lib/screenshots.ts` and an entry in `LOCKED_SHOTS`. It is shown only when `useFeatureLocked(feature)` is true, i.e. `billingStatus.features[feature]` is `false`, so it never shows while status loads or where plans are not enforced. Analytics and Offers both use it. `notifications` is deliberately not previewed: the API exposes the flag but gates nothing on it, so Free users still get reminders. `ApplicationCapNotice` (applications list) is the soft heads-up between 80% of the application limit and the cap, read from `billingStatus`, not `contentQuota`.
